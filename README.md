# سورس حمزة | يوزربوت تيليثون

يوزربoت شخصي في **ملف واحد** `main.py` — بدون بوت مساعد، بدون inline keyboard،
بدون قواعد بيانات خارجية. كل التخزين عبر ملفات **JSON** منفصلة داخل مجلد `data/`.

## التنصيب

```bash
pip3 install -r requirements.txt
```

انسخ الإعدادات واملأها:

```bash
cp config.example.json config.json
```

عدّل `config.json`:

| الفار | الشرح |
|------|-------|
| `API_ID` | من https://my.telegram.org |
| `API_HASH` | من https://my.telegram.org |
| `STRING_SESSION` | كود سيشن تيليثون |
| `PREFIX` | بادئة الأوامر (افتراضي `.`) |
| `OWNER_NAME` | اسمك الظاهر (افتراضي `حمزة`) |

## التشغيل

```bash
python3 main.py
```

## الأوامر

أرسل `.الاوامر` لعرض الأقسام، ثم `.م1` ... `.م14` لكل قسم:

- **م1** الإدارة (حظر/كتم/رفع مشرف/تثبيت/مسح/تحذير)
- **م2** المجموعة (المشرفين/الأعضاء/معلومات/البوتات)
- **م3** الكشف والايدي
- **م4** الردود
- **م5** الترحيب
- **م6** حماية الخاص
- **م7** الإذاعة (للكروبات/للخاص)
- **م8** البوت (فحص/بنك/اعادة تشغيل)
- **م9** المنع والترجمة
- **م10** التكرار
- **م11** البروفايل
- **م12** الصيغ
- **م13** التسلية
- **م14** التحكم

## التخزين

كل ميزة لها ملف JSON خاص في `data/`:
`replies.json`, `warns.json`, `welcome.json`, `locked.json`,
`pm_allowed.json`, `settings.json`, `sudo_users.json` ...
