# سورس حمزة | يوزربوت تيليثون (Userbot)

يوزربوت شخصي في **ملف واحد** `main.py` — بدون بوت مساعد، بدون inline keyboard،
بدون قواعد بيانات خارجية. كل التخزين عبر ملفات **JSON** منفصلة داخل مجلد `data/`.

البادئة الافتراضية للأوامر: `.` (نقطة)
المالك الافتراضي: `حمزة`

---

## أولاً: تجهيز بيانات تيليجرام (API_ID و API_HASH)

قبل التنصيب تحتاج قيمتين من موقع تيليجرام الرسمي. الخطوات (مؤكدة من
https://core.telegram.org/api/obtaining_api_id):

1. **افتح الموقع:** ادخل على https://my.telegram.org
   (أو مباشرة https://my.telegram.org/apps)

2. **سجّل الدخول:** اكتب رقم هاتفك بالصيغة الدولية (مثال: `+967xxxxxxxxx`)
   ثم أدخل **كود التحقق** الذي سيصلك داخل تطبيق تيليجرام.
   - إن كان عندك تحقق بخطوتين (2FA) أدخل كلمة المرور أيضاً.

3. **ادخل لـ API development tools:** بعد الدخول ستظهر قائمة «Your Telegram Core»
   اختر **API development tools** (أدوات تطوير API).

4. **أنشئ تطبيقاً جديداً:** اضغط **Create new application** واملأ النموذج:
   - **App title** (عنوان التطبيق): أي اسم، مثال `Hamza Userbot`
   - **Short name** (اسم قصير): أي اسم، مثال `hamzabot`
   - **Platform** (المنصة): اختر أي شيء (مثلاً `Desktop`)
   - **Description** (الوصف): اتركه فارغاً أو اكتب أي شيء
   - **URL**: اتركه فارغاً
   ثم اضغط **Create application / Save**.

5. **انسخ القيمتين:** بعد الإنشاء ستظهر شاشة «App configuration» فيها:
   - `App api_id` ← رقم مثل `12345678`
   - `App api_hash` ← نص سداسي عشري طويل مثل `0123456789abcdef0123456789abcdef`

   انسخهما — ستحتاجهما عند تشغيل السورس.

> ⚠️ **أمان:** عامل `api_hash` كأنه كلمة مرور ولا تشاركه مع أحد.
> كل رقم هاتف يمكنه ربط `api_id` واحد فقط بحسابه. تأكد من نسخ القيم
> بدون مسافات زائدة قبلها أو بعدها (الـ `api_id` أرقام فقط والـ `api_hash` حساس للأحرف الكبيرة/الصغيرة).

6. **التشغيل:** بعد تنصيب السورس وتشغيله (`python main.py`) سيطلب منك
   إدخال `API_ID` و `API_HASH` مباشرة في الشاشة، ثم رقم الهاتف — بدون
   الحاجة لفتح `config.json` يدوياً. تحفظ القيم تلقائياً.

## 1) التنصيب على Termux (أندرويد)

حمّل تطبيق **Termux** من F-Droid (لا من المتجر القديم).

افتح Termux وانسخ السطر تلو الآخر:

```bash
# تحديث الحزم وتثبيت الأدوات
pkg update && pkg upgrade -y
pkg install -y git python python-pip

# تنزيل السورس
git clone https://github.com/Hmza1112617/Hamza-Userbot.git
cd Hamza-Userbot

# تثبيت المكتبات
pip install -r requirements.txt

# تجهيز الإعدادات
cp config.example.json config.json
```

> ✅ **لا تحتاج لفتح `config.json` يدوياً** — بعد تشغيل السورس مباشرة
> سيطلب منك (`API_ID` و `API_HASH`) ثم رقم الهاتف وكود التحقق، ويحفظ كل شيء تلقائياً.

التشغيل:

```bash
python main.py
```

في أول تشغيل سيسألك السورس:
- `API_ID` و `API_HASH` (إن لم تملأهما سابقاً).
- رقم هاتفك (مثلاً `+967xxxxxxxxx`).
- كود التحقق الذي يصلك على تيليجرام.
- (أحياناً) كلمة مرور التحقق بخطوتين.

بعد تسجيل الدخول سيُحفظ السيشن تلقائياً ولا تعيد هذه الخطوات مستقبلاً.

⚠️ **تنبيه:** عند إغلاق Termux يتوقف السورس. لتشغيله في الخلفية استخدم:

```bash
pkg install -y tmux
tmux new -s hamza
python main.py
# اخرج بـ: Ctrl+B ثم D  (يظل شغال)
# للرجوع: tmux attach -t hamza
```

## 2) التنصيب على سيرفر VPS (Linux)

عبر SSH ادخل للسيرفر ثم:

```bash
# تحديث النظام
sudo apt update && sudo apt upgrade -y

# تثبيت git و python
sudo apt install -y git python3 python3-pip

# تنزيل السورس
git clone https://github.com/Hmza1112617/Hamza-Userbot.git
cd Hamza-Userbot

# تثبيت المكتبات
pip3 install -r requirements.txt

# تجهيز الإعدادات
cp config.example.json config.json
```

> ✅ **لا تحتاج لفتح `config.json` يدوياً** — السورس عند التشغيل يطلب
> `API_ID` و `API_HASH` ورقم الهاتف مباشرة ويحفظها تلقائياً.

التشغيل المباشر:

```bash
python3 main.py
```

لتشغيله دائماً في الخلفية (حتى بعد قطع اتصال SSH) يُفضّل `screen` أو `tmux`:

```bash
# باستخدام screen
sudo apt install -y screen
screen -S hamza
python3 main.py
# Ctrl+A ثم D  (للفصل والإبقاء شغال)
# العودة: screen -r hamza
```

أو عبر `tmux`:

```bash
sudo apt install -y tmux
tmux new -s hamza
python3 main.py
# Ctrl+B ثم D
# العودة: tmux attach -t hamza
```

في أول تشغيل سيطلب رقم الهاتف وكود التحقق كما في Termux.

| `API_ID` | من my.telegram.org | — |
| `API_HASH` | من my.telegram.org | — |

## الأوامر

أرسل `.الاوامر` لعرض الأقسام، ثم `.م1` ... `.م17` لكل قسم:

- **م1** الإدارة (حظر/كتم/رفع مشرف/تثبيت/مسح/تحذير)
- **م2** المجموعة (المشرفين/الأعضاء/معلومات/البوتات)
- **م3** الكشف والايدي
- **م4** الردود
- **م5** الترحيب
- **م6** حماية الخاص
- **م7** الإذاعة (للكروبات/للخاص)
- **م8** البوت (فحص/بنك/اعادة تشغيل)
- **م9** المنع والترجمة
- **م10** التكرار
- **م11** البروفايل
- **م12** الصيغ
- **م13** التسلية
- **م14** التحكم
- **م15** الذكاء الاصطناعي
- **م16** التحديثات (`.تحديث` / `.تحديثات` / `.اخر_تحديث`)
- **م17** باند وشد (فحص الروابط + البلاغات)

### قسم الذكاء (م15)

- `.ذكاء <سؤال>` — محادثة مع الذكاء
- `.ذكاء مفعل` — تفعيل الوضع الشامل (ينفّذ أوامر Telethon فعلياً)
- `.ذكاء تشغيل` / `.ذكاء تعطيل` — الرد التلقائي بالخاص
- `.ذكاء ذاكرة مسح` — مسح ذاكرة المحادثة
- `.دليل الذكاء` — توليد دليل السورس
- `.ادوات الذكاء` — عرض أدوات Telethon

### قسم الشد (م17)

أوامر ضبط منفصلة:

- `.شد_هدف <رابط/يوزر>` — يضع هدف البلاغ
- `.شد_نوع <نوع>` — نوع المخالفة (سبام/اباحي/عنف/تحرش/حقوق/وهمي/غير_قانوني/اخر)
- `.شد_رساله <نص>` — نص رسالة البلاغ
- `.شد_سرعه <ثواني>` — سرعة التأخير بين البلاغات (1-60)

التشغيل:

- `.شد <رابط/يوزر>` — يبدأ البلاغ المستمر (يفحص كل دورة هل الهدف محظور ويتوقف تلقائياً)
- `.شد_ايقاف` — إيقاف يدوي
- `.شد_اعداد` — عرض الإعدادات
